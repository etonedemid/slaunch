# sLaunch Chinese locale (Simplified). Generated from template.txt.
#
# Filed as zh.txt rather than zh-Hans.txt on purpose: the loader tries the full
# system code first and then the two-letter one, so this single file is picked
# up by every Chinese console (zh-Hans, zh-CN, zh-Hant, zh-TW). Traditional
# users get Simplified until a zh-Hant.txt exists; drop one in the same folder
# and it wins automatically.
#
# The menu selects the console's own Chinese shared font from the system
# language, so these glyphs render without installing anything.
